Primetech - Sauvegarde et base de test

Automatisez la sauvegarde de production et la création d'une base de test sécurisée.

Manuel d'utilisation

  1. Dans Sauvegarde et test, cliquez sur Nouveau.
  2. Renseignez le dossier de sauvegarde, le nom de la base de test et l'heure souhaitée.
  3. Enregistrez le plan et conservez-le actif pour l'exécution automatique.
  4. Le bouton Lancer maintenant permet une exécution immédiate.
  5. Le menu Journal affiche chaque sauvegarde, sa taille, son statut et les erreurs.

Attention : la base de test est remplacée à chaque exécution. Les emails sortants sont neutralisés dans la copie.
